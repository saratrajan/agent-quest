Your GPT has a context of 128 characters because its position table has 128 rows and generate keeps only the last 128 tokens. Everything earlier is gone: the model cannot recall it, however important it was. Every language model has this limit. The only thing that changes is the number.

The window is a budget, counted in tokens, shared by everything in one request:

Goes into the windowFor a triage agent
Instructionswhat triage means here, the output format
The taskthe new incident's summary and description
Supplied knowledgepast incidents, runbook steps, service details
The model's own outputits reasoning and its answer

Two things about the window are easy to get wrong.

  • The configured window is often far smaller than the model's maximum. The model on this Mac supports 262,144 tokens, but the software running it uses a much smaller default, because memory and time grow with the window. A prompt longer than the configured window is cut, and nothing warns you. In the second experiment you will watch a fact at the start of a long prompt vanish for exactly this reason.
  • A larger window is not free. Session 3 showed that attention's work grows with the square of the length. Long prompts are slower to start answering, cost more, and can dilute the passage that matters among ones that do not.

This is the reason retrieval exists. An agent cannot be handed all 400 past incidents on every request, and should not be. From session 7 you build the step that chooses the handful worth the space.
