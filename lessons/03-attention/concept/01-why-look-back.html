The bigram model from session 2 predicts from one token. Consider what that throws away. Both of these end in the same word:

Card payments are failing  →  likely next: "at the 3-D Secure step"
Unit tests are failing     →  likely next: "on the main branch"

Seen from the last token alone, the two are identical. What should come next depends on a word several positions back. A useful model needs every position to draw on the earlier tokens that matter to it, however far back they are.

The crudest way to give a position some context is to average the vectors of everything before it. That mixes in the past, but treats every earlier token as equally important, and "are" matters far less than "payments" here.

Attention is a weighted average where the weights are computed from the content. Each position asks a question, every earlier position offers a description of itself, and the better a description matches the question the more weight that position gets. In the sentence above, the position after "failing" can put most of its weight on "payments".

Three things to carry into the next step:

  • The output for a position is a blend of earlier positions' information, not a single one chosen.
  • The weights in the blend are learned to be useful for predicting the next token. Nobody tells the model what to look at.
  • The weights for one position always sum to 1, because they come from a softmax, the same function you wrote in session 2.
