Each token's vector is turned into three smaller vectors by three learned projections:

  • a query: what this position is looking for;
  • a key: what this position can be found by;
  • a value: what this position hands over if it is attended to.

The score between a query and a key is their dot product, large when they point the same way. The scores go through a softmax to become weights, and the output is the weighted sum of the values:

Attention(Q, K, V) = softmax( Q KT / √d ) V

Work the third position of a three-token example by hand. Vectors have d = 2 numbers, so the scaling is √2 = 1.414.

PositionKeyValueQuery 3 · key÷ √2escoreWeight
1[1, 0][1, 0]10.7072.0280.248
2[0, 1][0, 1]10.7072.0280.248
3[1, 1][2, 2]21.4144.1130.503

Query 3 is [1, 1]. The output for position 3 is 0.248 × [1, 0] + 0.248 × [0, 1] + 0.503 × [2, 2] = [1.255, 1.255]. Those are the numbers your first test checks.

Why divide by √d? A dot product adds up d terms, so its size grows with d. Large scores push the softmax to put nearly all the weight on one token, and a softmax in that state passes back almost no gradient, so the head stops learning. Dividing by √d keeps the scores at a steady size whatever the dimension. You will measure this in the first experiment.

Source: Vaswani et al. (2017), Attention Is All You Need, section 3.2.
