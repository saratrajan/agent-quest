Stacking blocks naively does not train. Each layer transforms its input, and after several layers the signal reaching the first one during backpropagation has been multiplied so many times that it has faded or blown up. Two devices fix this, and both appear in the three lines of Block.forward you are about to write.

Residual connections. A sub-layer does not replace its input; it adds a correction to it:

x ← x + attention(norm(x)) then x ← x + feed_forward(norm(x))

There is now a direct path from the output back to every layer, along which the gradient passes unchanged. If a sub-layer has nothing useful to add yet it can output zeros and the block passes its input straight through, which is why your test silences both sub-layers and checks that the block returns its input exactly.

Layer normalisation. Before each sub-layer, each position's vector is rescaled to have mean 0 and spread 1 (with a learned scale and shift). Whatever earlier layers did, every sub-layer sees inputs of a steady size.
